What's inside

Every row is one submission:

  • task_id, input (the task content)
  • output (the annotator's answer)
  • status, qa_score
  • annotator_id (numeric id, not a name)
  • submitted_at, reviewed_at (UTC)
  • is_gold — was this a checked task
  • gold — the answer key, only when included above

Every export is recorded in the audit trail (what format, how many rows) — never the data itself. Annotators stay pseudonymous: ids only, no names or emails in dataset files.
